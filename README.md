# 像素生存者2 钻石手账

一个纯静态、本地优先的 PWA。用于记录宝箱和钻石奖励的下一次领取时间，并查看本日、本周、本月的钻石收益。

## 已实现功能

- 宝箱默认每 70 分钟刷新，钻石奖励默认每 45 分钟刷新
- 旧版本中仍为初始值 60/30 分钟的数据会在首次加载时迁移为 70/45，自定义的其他间隔保持不变
- 点击“下一个”后，以手机当前时间计算预计领取时间
- 宝箱领取后可快速选择本次收益 0、1、2 钻石，未选择时默认 2
- 钻石奖励每次固定记录 2 钻石
- 任意连续 60 秒内最多记录 6 钻石，避免重复点击造成误差
- 单领和双领均支持 5 秒内撤回
- 本日、本周、本月收益统计
- 奖励与数据双页面底部导航
- 7 天与 30 天每日数据趋势和折线分析
- 可导出今日、本周、本月、指定月份或今年数据的 3840×2160 PNG 简报
- 年度汇总简报包含年度总额、活跃天数、来源构成和按月趋势
- 4K 简报使用当前主题色和浅色/深色模式，全程在本机生成
- 首页顶部显示手账已陪伴天数和累计获得钻石
- 点击折线节点查看当天收益构成与环比变化
- 连续记录天数和 7 日移动平均趋势
- 点击钻石统计卡查看明细并删除错误记录
- 宝箱与钻石奖励到点系统通知，并支持发送测试通知
- 点击“下一个”或“一起领取”时提供轻量震动反馈
- 首页提供 BOSS、种子、额外宝箱、每日任务、角色卡合成和天天送礼物入口
- 每日任务每天最多记录一次并增加 5 钻石；天天送礼物每天最多记录两次
- BOSS、种子和额外宝箱每个按钮在 5 秒滚动窗口内最多记录两次
- 额外来源点击会播放波纹、图标弹跳、棱形钻石飞行动画，并短暂显示今日总钻石
- 额外来源提供 5 秒撤销入口，冷却与每日完成状态均有独立提示
- 像素小助手会根据今日钻石总量选择不同的鼓励文案
- 设置中可以关闭首页每日任务板块，已有每日任务记录不会被删除
- 昵称和头像保存在本机
- 9 套主题色、深色模式
- 像素小助手显示今日领取次数和钻石数据
- 一键加群弹窗和官方 QQ 群名片跳转
- 按钮按压使用 3D 回弹效果与 120Hz 固定步长彩带烟花动画
- PWA 离线缓存

## 数据说明

- 页面没有后端、账号、数据库或远程接口
- 昵称、设置和当前领取状态保存在 localStorage
- 领取历史和头像保存在 IndexedDB
- 除首次加载和版本更新外，断网也能使用
- 清除浏览器数据、卸载 PWA 或更换手机会导致本地记录丢失

## 4K 简报

- 首次使用时间保存在 `profile.startedAt`；旧数据会优先使用最早一条领取记录回填。
- 首页陪伴天数按本机自然日计算，首次使用当天记为第 1 天。
- 4K 简报在浏览器或 WebView 内通过 Canvas 生成，不上传昵称、头像或领取记录。
- 今日简报按小时绘制，本周、本月和指定月份按天绘制，今年简报按已结束月份绘制。
- 导出文件包含品牌版头、用户头像与昵称、简报类型、指标图标、趋势折线、来源构成和最高收益时段/日期/月份。

## 本地预览

在本目录运行：

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 免费部署

将本目录的全部文件上传到任意静态网站服务即可，不需要部署 Node.js、Python 或其他后端：

- Netlify Drop
- GitHub Pages
- EdgeOne Pages
- 其他支持 HTTPS 的免费静态托管

上传时根目录应包含 `index.html`、`manifest.webmanifest`、`sw.js` 和 `assets/`。

iPhone 使用 Safari 打开 HTTPS 地址，点击分享按钮，选择“添加到主屏幕”。

安卓使用 Chrome 打开地址，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。

安卓图标已额外提供安全区 maskable 版本、旧版启动器尺寸，以及可用于后续 APK 的
自适应前景/背景素材，位于 `assets/android/`。

## 更新注意

每次正式发布界面或脚本更新时，必须同步提升资源版本号，例如从 `v9` 改为 `v10`。

可运行以下命令自动升号并检查：

```powershell
pwsh -NoProfile -File scripts/bump-version.ps1 -Version 10
pwsh -NoProfile -File scripts/check-release.ps1
```

手动修改时必须同步更新：

- `index.html` 中的 `styles.css?v=9`、`app.js?v=9` 和 `manifest.webmanifest?v=9`
- `app.js` 中 Service Worker 的 `sw.js?v=9`
- `sw.js` 中的 `CACHE_NAME` 和 `APP_SHELL` 资源地址

所有位置必须使用同一个版本号。这样可以避免已安装用户第一次打开时，出现新 HTML 搭配旧 CSS/JS 的界面错乱。`localStorage` 和 `IndexedDB` 不需要清理，程序资源缓存更新不会删除用户记录。

## 网页通知限制

网页版会在应用打开、切到后台但仍由浏览器存活时检查领取时间，到点后通过 Service Worker 发送系统通知。普通网页完全退出后无法保证继续执行定时器；需要关闭应用后仍可靠提醒的 Android 用户应安装 APK。

iOS 网页与主屏幕 PWA 无法可靠执行本地后台定时通知，因此当前版本在 iOS 上直接禁用该功能，不请求通知权限，也不会创建后台提醒计时器。

## 震动反馈限制

领取按钮使用浏览器 Vibration API：单独领取为一次 18ms 轻震，同时领取为轻量双震。Android Chrome 和兼容浏览器会实际震动；iOS Safari/PWA 目前不开放网页震动接口，因此会自动跳过，不影响领取操作。

## 额外钻石来源

首页底部按钮会把每次点击记录为独立的 `source` 事件，因此可以进入“钻石明细”删除误触记录。每日任务使用独立横向卡片，展示任务图标、每日 5 钻石说明和钻石奖励；天天送礼物使用礼物图标和文字按钮。每日任务和天天送礼物按本机自然日计数，删除对应记录会恢复当天次数。

每日任务使用的任务图标来自 Lucide `clipboard-check` 图标，项目采用 ISC License。

额外的钻石飞行动画使用现有 `assets/diamond.png`。点击普通来源生成一颗飞行动画，每日任务生成五颗。飞行使用 120Hz 时间步长并持续约 1.2 秒，顶部大型玻璃卡片同步显示本次增加量与今日总钻石。页面进入不播放位移或淡入动画，以保证启动速度。

宝箱、钻石和双领按钮的撤销同样使用底部全局撤销条。原有 5 秒撤销能力和按钮本身的文字、图标、尺寸、动画保持不变。三个主按钮成功记录后也会触发钻石飞行动画：单领默认生成 2 颗，双领生成 4 颗。

宝箱领取后选择 0 或 1 钻石时，记录值、今日总钻石和顶部总钻石卡片都会立即按差额下调。
