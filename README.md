# 像素生存者2 钻石手账

一个纯静态、本地优先的 PWA。用于记录宝箱和钻石奖励的下一次领取时间，并查看本日、本周、本月的钻石收益。

## 已实现功能

- 宝箱默认每 60 分钟刷新，钻石奖励默认每 30 分钟刷新
- 点击“下一个”后，以手机当前时间计算预计领取时间
- 宝箱领取后可快速选择本次收益 0、1、2 钻石，未选择时默认 1
- 钻石奖励每次固定记录 2 钻石
- 任意连续 60 秒内最多记录 6 钻石，避免重复点击造成误差
- 单领和双领均支持 5 秒内撤回
- 本日、本周、本月收益统计
- 点击钻石统计卡查看明细并删除错误记录
- 昵称和头像保存在本机
- 9 套主题色、深色模式
- 像素小助手显示今日领取次数和钻石数据
- 一键加群弹窗和官方 QQ 群名片跳转
- 按钮按压使用 3D 回弹效果与 120Hz 固定步长彩带烟花动画
- PWA 离线缓存

## 数据说明

- 页面没有后端、账号、数据库或远程接口
- 昵称、设置和当前领取状态保存在 localStorage
- 领取历史和头像保存在 IndexedDB
- 除首次加载和版本更新外，断网也能使用
- 清除浏览器数据、卸载 PWA 或更换手机会导致本地记录丢失

## 本地预览

在本目录运行：

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 免费部署

将本目录的全部文件上传到任意静态网站服务即可，不需要部署 Node.js、Python 或其他后端：

- Netlify Drop
- GitHub Pages
- EdgeOne Pages
- 其他支持 HTTPS 的免费静态托管

上传时根目录应包含 `index.html`、`manifest.webmanifest`、`sw.js` 和 `assets/`。

iPhone 使用 Safari 打开 HTTPS 地址，点击分享按钮，选择“添加到主屏幕”。

安卓使用 Chrome 打开地址，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。

安卓图标已额外提供安全区 maskable 版本、旧版启动器尺寸，以及可用于后续 APK 的
自适应前景/背景素材，位于 `assets/android/`。

## 更新注意

修改静态文件正式发布时，请同步修改 `sw.js` 中的 `CACHE_NAME`，例如从 `v1` 改为 `v2`，避免已安装用户继续使用旧缓存。
